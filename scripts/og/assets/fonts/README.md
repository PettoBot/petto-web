# Fonts of the preview cards

`BalsamiqSans-Bold.ttf` and `BalsamiqSans-Regular.ttf` are Balsamiq Sans (https://github.com/balsamiq/balsamiq-sans), licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). They are only used at build time, by `scripts/og/render.mjs`, to draw the headlines and taglines of the preview cards into pictures; they are not served by the site. Keep this note and the license text with them if they are copied elsewhere.
